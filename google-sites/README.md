# Insertar Mi Ministerio en Google Sites

Abre `mi-ministerio.html` con un editor de texto y copia todo el contenido.
En Google Sites: **Insertar → Insertar (Incorporar) → Insertar código → Siguiente → Insertar**.
Ajusta el alto del bloque a aproximadamente 1100 px y publica.

El archivo es HTML y CSS legible y comentado. Incrusta la app actual; no es una
reescritura independiente del proyecto React ni incluye el backend en HTML.
Google Sites no ejecuta ese backend. La aplicación sigue dependiendo del hosting
actual y recibe sus actualizaciones. Los datos personales no se guardan en Google Sites.

El botón «Abrir aplicación» permite usar la sesión y almacenamiento fuera del marco.
Un navegador o una política de seguridad puede impedir la vista incrustada o el acceso
a cookies. En ese caso usa el botón o, en Sites, inserta directamente el enlace de la app.
No se ha probado la inserción en la cuenta Google Sites del propietario.

La descarga APK requiere Android; el modo sin conexión conserva las limitaciones
de la versión web. No confundir «Probar sin registrarme» con un almacén permanente.
