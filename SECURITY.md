# Seguridad

La beta no ha recibido una auditoría independiente. No uses datos sensibles para
probarla ni adjuntes copias personales a reportes públicos. Si descubres una falla
que exponga información, notifícala al mantenedor de forma privada antes de
publicar pasos de explotación. Nunca subas contraseñas o tokens al repositorio.

Las credenciales y la infraestructura del sitio publicado no están incluidas.
La demo funciona en memoria. La API requiere identidad verificada por la pasarela.
