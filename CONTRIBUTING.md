# Cómo colaborar

1. Crea una copia del repositorio y una rama para tu cambio.
2. Ejecuta `npm install`, `npm test` y `npm run build`.
3. Usa datos ficticios en ejemplos y capturas.
4. Abre una propuesta de cambio explicando qué mejora y cómo lo probaste.

Las verificaciones se ejecutan automáticamente al subir cambios a main y en
propuestas de cambio. Una compilación correcta no sustituye pruebas en teléfonos.
No publiques credenciales, copias de seguridad ni registros personales en issues.
No cambies reglas de cómputo del informe sin documentarlas y probarlas.
